# V13.5.0 — content-directed composition and motion lifecycle

- Twelve new composition primitives, integrated into automatic planning and explicit section requests.
- Four opening variants and three closing variants. Decorative orb/particles are opt-in.
- Neutral narrative styling by default; design.narrativeArc="storm-to-calm" restores that story treatment.
- Gauge fill uses min/max; handles zero, limits and negative ranges; invalid gauge shape is rejected.
- Dedicated exit steps, fade/slide navigation transitions, cancellation and reduced-motion paths.
- Added wipe and emphasisPulse primitives for explicit animation plans.
- Stronger browser measurement gates and per-slide screenshots; deferred manual/click content is exempt from autoplay visibility checks.
- Theme-token cover styling and a JavaScript-disabled reading fallback.
- Four reproducible showcase decks; declarative composition extension contract.
- Controlled token comparison command requiring matched briefs and supplied usage provenance.

Known limits: Browser/device certification is not complete. No provider token
measurement has been supplied. New composition aesthetics require rendered review.
The checker tests layout and runtime behavior, not factual accuracy or design taste.
